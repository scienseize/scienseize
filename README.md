## Notable Projects

**[Lakad](https://github.com/garcieee/LKD)**, Team *Lakad Kinetic Development*: winner at the **5th Poland–Philippines IT Business Summit Hackathon** (Oct 2026)

Walking navigation and crowd reporting for Makati. Commuters get routes that avoid reported hazards, file geotagged AR photo reports (faces are blurred on the server), and send SOS videos. The city triages everything in a ranked ticket queue with live traffic and forecast foot-traffic layers.

`Flutter` · `FastAPI` · `React + TypeScript` · `Mapbox` · `SQLite`

| Project | What it does | Built with |
|---|---|---|
| [BioSentry Intelligence](https://github.com/garcieee/BioSentry-Intelligence) | Early-warning dashboard for Philippine hospital wards. It ranks patients by NEWS2 so clinicians know who to see first, with per-clinician access and audited views | FastAPI · React · TypeScript |
| [PalmCards](https://github.com/scienseize/Palmcards) | Gesture-controlled editor and speech-rehearsal mirror. Edit notes with hand gestures, rewrite tone or length with an LLM, then get feedback on pace, fillers, gaze and posture | MediaPipe · Ollama · Claude API |
| [Energy Anatomy](https://github.com/scienseize/energy-anatomy) | Thesis research: roofline-based energy profiling of transformer components (Pythia 160M–6.9B on a T4), plus an evaluation of energy-saving substitutions | PyTorch · Zeus · NVML |
| [Learning Readiness Predictor](https://github.com/scienseize/learning-readiness-predictor) | Regression model that predicts student reading scores from background factors, served through a Streamlit app | scikit-learn · pandas · Streamlit |
